# ZenQ Office Extensions Hub (.zqe)

Kho lưu trữ và phân phối chính thức các tiện ích mở rộng (Extensions) cho bộ ứng dụng văn phòng **ZenQ Office**.

## Định dạng gói mở rộng `.zqe`
- Tệp nén chuẩn ZIP mang đuôi mở rộng `.zqe` (ZenQ Extension).
- Chứa `manifest.json` định nghĩa mã tiện ích, thông tin tác giả (`authorId`, `authorName`), danh mục và hành động tương thích.
- Hỗ trợ tải, cài đặt trực tiếp từ Cloud hoặc cài đặt thủ công ngoại tuyến.
- Người dùng có vai trò **Creator** hoặc **Admin** có quyền đăng tải và quản lý tiện ích của mình.
